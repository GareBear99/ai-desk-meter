# Security Policy

## Supported versions

This is an early DIY hardware/software scaffold. Security fixes should target the main branch until release tags are established.

## Reporting

Open a GitHub issue for non-sensitive bugs. For sensitive reports, contact the maintainer privately.

## Scope

This project must not be used to bypass account limits, automate quota evasion, scrape private dashboards, or exfiltrate secrets. Keep all providers local, user-authorized, and transparent.

## Secrets

Do not commit API keys, cookies, tokens, browser profiles, or private usage exports.
