# Contributing

Contributions are welcome for:

- Firmware board adapters
- Display drivers
- Safer provider integrations
- Enclosure CAD/STL files
- Documentation
- Host daemon improvements

Rules:

1. Do not add code that bypasses service limits.
2. Do not add private-dashboard scraping or cookie theft.
3. Mark estimated usage as estimated.
4. Keep device payloads minimal.
5. Add tests or sample payloads where possible.
