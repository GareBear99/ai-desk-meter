# Enclosure Guide

## v0.1 enclosure

Use a simple wedge stand:

- front display window
- USB-C cutout
- rear wedge angle
- rubber feet
- small vent slots

## Print checklist

- Measure exact board width/height/thickness.
- Measure USB-C port location.
- Leave tolerance for buttons and cable strain.
- Avoid blocking Wi-Fi/BLE antenna region.
- Do not include battery until USB build is stable.
