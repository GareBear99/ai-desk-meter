# Licensing Roadmap

This repository follows an open-source corridor before the planned commercial 3.0 package.

## Current public track

The current AI Desk Meter repo and the work leading up to the 3.0 package are intended to remain open source under the repository license unless explicitly changed in a future release.

| Track | Intended posture | Notes |
|---|---|---|
| v0.x | Open source | Hardware, host daemon, providers, dashboard groundwork |
| v1.x | Open source | Stable Arc-RAR-backed AI Desk Meter path |
| v2.x | Open source | Expanded local workflow/dashboard integrations |
| v3.0 | Planned commercial license | MuseMeter full package / second-brain / Neural Synth / AI buddy product |

## MuseMeter 3.0 direction

MuseMeter 3.0 is planned as the commercial full package: a second-brain style local AI buddy with Neural Synth interface concepts, richer agent states, and product-grade packaging.

The current “Musing...” state is intentional. It means the agent is responding to prompt input or an action is loading. Later versions can differentiate states such as thinking, loading, archiving, verifying, warning, and responding.

Before public commercial launch, final product naming should receive normal trademark/domain review.
