DIY / Cost Specs

Build-ready hardware sourcing for the AI Desk Meter. These are guidance estimates and source categories, not required purchases from one vendor.

Recommended core boardWaveshare ESP32-S3-Touch-AMOLED-2.16

2.16-inch 480×480 capacitive AMOLED ESP32-S3 board. Search exactly: ESP32-S3-Touch-AMOLED-2.16.

Best first sourceWaveshare official store

Use the official product page to verify SKU, battery option, and current board pricing before checking marketplaces.

Docs / firmware sourceWaveshare Docs + GitHub + Espressif BSP

Use vendor docs/sample code and Espressif registry entries for pinout, display, touch, IMU, audio, and flashing references.

Convenience sourceAmazon / regional marketplace

Search: Waveshare ESP32-S3 2.16 AMOLED Touch. Confirm it is the 2.16-inch model, not 2.06 or 2.41.

Required extrasUSB-C data cable + runtime host

Use a data-capable USB-C cable. Runtime host can be Mac, Windows, Linux, or Raspberry Pi writing runtime/status.json.

Optional build polish3D case, stand, screws, battery option

Search for an ESP32-S3 AMOLED 2.16 case or print/custom-fit one. Battery is optional; USB-powered is simplest.

Cheap prototype$25–$60

Board or cheaper ESP32 display, USB cable, no polished case. Good for protocol and UI proof.

Best-match desk build$50–$120 all-in

Recommended Waveshare 2.16 AMOLED board, cable, simple enclosure/stand, basic finish.

Product-style one-off$90–$160

Board, polished enclosure, fasteners, rubber feet, cable management, optional battery/power polish.

Rule: ESP32/Arduino-class boards are companion displays. The desktop/Pi host remains the backend/source-of-truth runtime.
